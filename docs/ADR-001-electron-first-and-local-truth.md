# ADR-001: اعتماد مسار Electron أولاً، وأرشفة WPF، والتخزين المحلي مصدراً للحقيقة

- **الحالة**: معتمد (Accepted)
- **التاريخ**: 2026-11-24
- **السياق**:
  أظهر التدقيق المعماري والأمني وجود مسارين متوازيين (تطبيق سطح مكتب Electron + React/Vite وتطبيق WPF قديم داخل `ThanaweyaAmma/`) وثلاث أشجار ترحيل متفرقة لقواعد البيانات، مما شتّت اختبارات القبول والضمان التعليمي.

## القرارات المعمارية المعتمدة

1. **مسار التطبيق الوحيد النشط (Electron-First)**:
   - تطبيق Windows المكتبي المبني على `electron/` و`src/` و`server/app.ts` هو المسار الرسمي الوحيد للتطوير والبناء والإصدار.
   - أرشفة مشروع WPF داخل `ThanaweyaAmma/` وإخراجه تماماً من مسارات البناء والاختبار الآلي (CI).

2. **البيانات المحلية مصدراً للحقيقة (Local-First Persistence)**:
   - تُحفظ محاولات الطالب (`StudyAttempt`) ودفتر الأخطاء (`MistakeEntry`) وجدول المراجعة المتباعدة (`1 / 3 / 7 / 14` يوماً) محلياً عبر `IndexedDB` مع مرآة متزامنة للعمل الكامل دون اتصال بالإنترنت.
   - في الإصدار الأول المخصص للقُصَّر (10–20 طالباً تجريبياً)، **لا يُفرض إنشاء حساب سحابي** أو إرسال بيانات القُصَّر إلى مزودي نماذج لغوية دون موافقة صريحة.

3. **ربط المحاولات بنسخة السؤال وحاجز المراجعة (Content Gate)**:
   - كل محاولة طالب تُسجل مرتبطةً بـ `(questionId, questionVersion)`.
   - لا يظهر أي سؤال للطلاب في التدريب أو الاختبار أو التخطي إلا إذا كان `reviewStatus === 'reviewed'` ومُراجَعاً من معلم رياضيات ومتحققاً منه رياضياً.
   - شجرة الترحيل السحابية الوحيدة المعتمدة مستقبلاً هي `supabase/migrations/`.

4. **الأمان وعزل العمليات (Defense in Depth)**:
   - عزل عمليات الملفات في Electron داخل مجلدات التطبيق المخصصة فقط (`student_workspace`, `Documents/ThanaweyaAmma`, `Downloads/ThanaweyaAmma`)، مع حظر تيارات NTFS البديلة (`evil.exe::$DATA`) وأسماء أجهزة Windows المحجوزة والاختصارات والمثبّتات.
   - حماية الخادم المحلي `127.0.0.1` ضد DNS Rebinding والعمليات المحلية الأخرى عبر التحقق من ترويسة `Host` و`Origin` وتوكن جلسة عشوائي يتجدد مع كل تشغيل (`X-Thanaweya-Session`).

## التبعات
- أي أداة تعليمية جديدة يجب أن تمر ببوابة الاختبارات الآلية (`npm test`: فحص الأنواع + KaTeX + مخطط المحتوى + أمان المسارات والحلقة المحلية + منطق التكرار المتباعد).
- إزالة أي مؤشرات قلق أو ادعاءات غير محققة من واجهة الطالب (السلاسل اليومية، درجات متوقعة، نسبة إتقان مصطنعة، أو وسم «تم الحفظ» قبل إتمام الكتابة الفعلية).
