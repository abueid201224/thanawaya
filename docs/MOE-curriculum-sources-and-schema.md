# المصادر الرسمية المعتمدة للمناهج والتقييمات (وزارة التربية والتعليم المصرية)

تُستخدم هذه المصادر المرجعية الرسمية لتوثيق وحدات المنهج، نواتج التعلم، والأسئلة المراجَعة قبل إتاحتها للطلاب عبر بوابة المحتوى (`reviewStatus = 'reviewed'`):

1. **بوابة الكتب الدراسية للمرحلة الثانوية**
   - `https://studentbooks.moe.gov.eg/books/Books-sec/`
   - المرجع الأساسي لكتب الطالب الرسمية في مواد الرياضيات البحتة والتطبيقية والفيزياء.

2. **المكتبة الإلكترونية — كتب المرحلة الثانوية**
   - `https://ellibrary.moe.gov.eg/Books/Books-sec/`
   - المرجع الرسمي للأدلة الدراسية وكتب الوزارة بصيغة إلكترونية.

3. **الأداءات والتقييمات الرسمية**
   - `https://ellibrary.moe.gov.eg/Performance_Assessments`
   - المرجع الرسمي للأداءات الصفية والمنزلية والتقييمات الأسبوعية والشهرية لربط كل سؤال بمخرج تعلم موثق ومصدر محدد.

## حقول المخطط المطلوبة عند استيراد المحتوى (SQLite / Content Schema)
- `source_url`: أحد الروابط الرسمية أعلاه (أو رابط الوثيقة PDF المشتقة منه).
- `academic_year`: مثال `2026/2027`.
- `subject_code` و `unit_number` و `learning_outcome`.
- `question_version` (`>= 1`) و `review_status` (`unreviewed` افتراضياً ولا يظهر للطلاب إلا بعد التحول إلى `reviewed` بواسطة مراجع المادة).
