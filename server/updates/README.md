# Auto-Update Server Configuration

This directory contains configuration files for the auto-update system.

## How Auto-Update Works

The application uses `electron-updater` to check for and download updates. Here's the flow:

1. **Client checks for updates** → Sends request to update server
2. **Server responds** → With `app-update.yml` file containing version info
3. **Client compares versions** → If newer version available, downloads
4. **Client downloads** → Downloads new installer/executable
5. **Client installs** → Replaces old version and restarts

## Setup Options

### Option A: GitHub Releases (Recommended for Open Source)

1. Configure `electron-builder.yml`:
```yaml
publish:
  - provider: "github"
    owner: "abueid201224"
    repo: "thanawaya"
    token: "${GITHUB_TOKEN}"
```

2. The update URL will be automatically generated by GitHub

### Option B: Self-Hosted Update Server

#### Requirements:
- HTTPS server (required for security)
- Static file hosting
- CORS configured to allow your app domain

#### Setup Steps:

1. **Create update directory structure:**
```
updates/
├── app-update.yml          # Main update manifest
├── stable/                 # Stable channel
│   └── app-update.yml
├── beta/                   # Beta channel
│   └── app-update.yml
├── alpha/                  # Alpha channel
│   └── app-update.yml
└── files/                 # Actual update files
    ├── ThanaweyaAmmaMathCopilot-Setup-1.0.0.exe
    └── ThanaweyaAmmaMathCopilot-Portable-1.0.0.exe
```

2. **Configure `electron-builder.yml`:**
```yaml
publish:
  - provider: "generic"
    url: "https://your-update-server.com/updates"
    channel: "stable"
```

3. **Set environment variable:**
```bash
# In your build process
export UPDATE_FEED_URL="https://your-update-server.com/updates"
```

### Option C: AWS S3 Bucket

1. Create S3 bucket with public read access
2. Upload files to bucket
3. Configure `electron-builder.yml`:
```yaml
publish:
  - provider: "s3"
    bucket: "thanaweya-updates"
    region: "us-east-1"
    accessKeyId: "${AWS_ACCESS_KEY_ID}"
    secretAccessKey: "${AWS_SECRET_ACCESS_KEY}"
```

### Option D: Netlify/Vercel

1. Deploy static files to Netlify/Vercel
2. Configure `electron-builder.yml`:
```yaml
publish:
  - provider: "generic"
    url: "https://thanaweya-updates.netlify.app/updates"
```

## Generating SHA256 Hashes

To generate SHA256 hashes for your update files:

### On Linux/macOS:
```bash
# For Windows installer
sha256sum ThanaweyaAmmaMathCopilot-Setup-1.0.0.exe | awk '{print $1}'

# For portable executable
sha256sum ThanaweyaAmmaMathCopilot-Portable-1.0.0.exe | awk '{print $1}'
```

### On Windows:
```powershell
# For Windows installer
Get-FileHash -Algorithm SHA256 ThanaweyaAmmaMathCopilot-Setup-1.0.0.exe | Select-Object -ExpandProperty Hash

# For portable executable
Get-FileHash -Algorithm SHA256 ThanaweyaAmmaMathCopilot-Portable-1.0.0.exe | Select-Object -ExpandProperty Hash
```

### Using Node.js:
```javascript
const crypto = require('crypto');
const fs = require('fs');

function getSHA256(filePath) {
  const fileBuffer = fs.readFileSync(filePath);
  const hashSum = crypto.createHash('sha256');
  hashSum.update(fileBuffer);
  return hashSum.digest('hex');
}

console.log(getSHA256('ThanaweyaAmmaMathCopilot-Setup-1.0.0.exe'));
```

## Example: Complete Update Server Setup with Nginx

### 1. Install Nginx

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install nginx

# Start and enable
sudo systemctl start nginx
sudo systemctl enable nginx
```

### 2. Configure Nginx

Create `/etc/nginx/sites-available/thanaweya-updates`:

```nginx
server {
    listen 443 ssl http2;
    server_name updates.yourdomain.com;
    
    ssl_certificate /path/to/your/cert.pem;
    ssl_certificate_key /path/to/your/key.pem;
    
    root /var/www/thanaweya-updates;
    index app-update.yml;
    
    location / {
        try_files $uri $uri/ =404;
        
        # CORS headers
        add_header 'Access-Control-Allow-Origin' '*'];
        add_header 'Access-Control-Allow-Methods' 'GET, OPTIONS';
        add_header 'Access-Control-Allow-Headers' 'DNT,User-Agent,X-Requested-With,If-Modified-Since,Cache-Control,Content-Type,Range';
        add_header 'Access-Control-Expose-Headers' 'Content-Length,Content-Range';
        
        # Cache control
        add_header 'Cache-Control' 'no-cache, no-store, must-revalidate';
        add_header 'Pragma' 'no-cache';
        add_header 'Expires' '0';
    }
    
    location ~ \.exe$ {
        types {}
        default_type application/octet-stream;
        add_header 'Content-Disposition' 'attachment';
    }
}

server {
    listen 80;
    server_name updates.yourdomain.com;
    return 301 https://$host$request_uri;
}
```

Enable the site:
```bash
sudo ln -s /etc/nginx/sites-available/thanaweya-updates /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### 3. Deploy Update Files

```bash
# Create directory
sudo mkdir -p /var/www/thanaweya-updates

# Copy files
sudo cp -r server/updates/* /var/www/thanaweya-updates/

# Set permissions
sudo chown -R www-data:www-data /var/www/thanaweya-updates
sudo chmod -R 755 /var/www/thanaweya-updates
```

## Testing Update Server

### 1. Test with curl:
```bash
# Check if app-update.yml is accessible
curl -I https://updates.yourdomain.com/app-update.yml

# Download the file
curl -O /tmp/app-update.yml https://updates.yourdomain.com/app-update.yml
```

### 2. Test in development:

Add to your `electron/main.ts`:
```typescript
// For development testing
if (!app.isPackaged) {
  updateService['config'].feedUrl = 'https://updates.yourdomain.com';
  updateService.startAutoCheck();
}
```

### 3. Force update check:
```typescript
// In your renderer process
electronAPI.checkForUpdates();
```

## Version Management

### Creating a New Version

1. **Build the new version:**
```bash
npm run build:all
npm run package:win
```

2. **Generate hashes:**
```bash
# Get file sizes
ls -lh release/

# Generate SHA256 hashes
sha256sum release/ThanaweyaAmmaMathCopilot-Setup-1.0.1.exe
sha256sum release/ThanaweyaAmmaMathCopilot-Portable-1.0.1.exe
```

3. **Update app-update.yml:**
```yaml
currentVersion: "1.0.1"

files:
  - url: "ThanaweyaAmmaMathCopilot-Setup-1.0.1.exe"
    sha256: "NEW_SHA256_HASH"
    size: NEW_FILE_SIZE
    channel: "stable"
    platform: "win32"
    arch: "x64"
    
  - url: "ThanaweyaAmmaMathCopilot-Portable-1.0.1.exe"
    sha256: "NEW_SHA256_HASH"
    size: NEW_FILE_SIZE
    channel: "stable"
    platform: "win32"
    arch: "x64"

releaseNotes:
  "1.0.1":
    ar: "إصلاحات أخطاء طفيفة وتحسينات في الأداء"
    en: "Bug fixes and performance improvements"
```

4. **Upload files to server:**
```bash
# Copy new files
scp release/* user@server:/var/www/thanaweya-updates/files/
scp server/updates/app-update.yml user@server:/var/www/thanaweya-updates/
```

## Troubleshooting

### "No update available"
- Check that `currentVersion` in app-update.yml is newer than your app version
- Verify the update server URL is correct
- Check that the app-update.yml file is accessible

### "Update download failed"
- Verify SHA256 hashes are correct
- Check file sizes are correct
- Ensure files exist at the specified URLs
- Test downloading files manually with curl

### "Signature verification failed"
- This happens when code signing is enabled but certificate is not trusted
- For development, you can disable signing in electron-builder.yml:
```yaml
win:
  sign: false
```

### "Network error"
- Check internet connection
- Verify CORS headers on server
- Test with curl to see if server is responding

## Security Considerations

1. **Always use HTTPS** - Never use HTTP for update servers
2. **Code Signing** - Sign your updates to prevent tampering
3. **Verify Hashes** - Always verify SHA256 hashes before installing
4. **Version Validation** - Ensure version numbers follow semantic versioning
5. **Access Control** - Restrict write access to update files
6. **Monitoring** - Monitor update server for suspicious activity
